# Surface 조사 결과와 수정 순서 — 2026-11-18

세부 근거는 `docs/investigations/2026-11-18-hardware-check/HARDWARE-CHECK.md`, 절전 시험은 `docs/investigations/2026-11-17-sync-state-trial/SYNC-STATE-TRIAL.md`.

## 목표

1. 모든 하드웨어 부품 정상 사용
2. 깨어 있을 때 배터리 소모 최적화 (지금 약 4.2~4.4W, 밝기 39%, 120Hz)
3. 절전 중 배터리 소모 최적화 (지금 0.52~0.89W, 목표 약 0.27W)

지켜야 할 조건: 120Hz와 원래 CPU 거버너·범위 유지, 재부팅은 매번 승인, 한 번에 한 가지만 바꾸고 전후를 측정.

## 조사로 확인한 것

| 항목 | 결과 |
| --- | --- |
| 하드웨어 1단계 | CPU, 메모리, 센서, SSD, 화면·GPU, 키보드, 터치패드, 터치스크린, 덮개, 스피커·마이크, 카메라, Wi-Fi, 블루투스, 배터리, USB-C 두 포트, Surface Connect 충전, USB-A 정상 |
| 스피커 PCM 항상 열림 | 오디오 DSP가 쉬지 못함. 깨어 있을 때 **−0.58W**, 절전 중 **0.2~0.3W** 차이 (DSP가 쉰 절전 0.52·0.66W, 못 쉰 절전 0.83·0.89W) |
| 절전에서 바로 깨어나는 원인 | `sync_state=timeout`이면 SoC 전체 절전(CXSD)에 들어가지만, **아무것도 꽂지 않은 USB-C 두 포트의 SuperSpeed PHY 깨우기 인터럽트(PDC 17, 47)가 계속 켜져** 2초 만에 깨어남 |
| a400000 (USB-A·Surface Connect 데이터) | 리눅스 시작 전 단계가 12~18초 길어진 부팅에서, 지연 초기화 시간 초과와 USB 모듈 로드가 겹쳐 실패 (시험 부팅에서는 매번 실패) |
| 동영상 재생 | 하드웨어 디코더가 꺼져 있어 1080p 재생 시 **+4.3W** (4.4 → 8.9W) |
| GNOME 확장, Waydroid, ASPM | 대기 전력 영향 측정 오차 수준 |
| 카메라 표시등 | 하드웨어 정상, 카메라와 연결 설정(DT) 없음 |
| 외부 모니터 | 출력되지만 연결까지 2~39초, 원인 미분석 |
| 시간 동기화 | NTP 서비스 없음 |
| Windows Hello IR 카메라 | 리눅스 지원 없음 (별도 과제) |

## 수정 순서 제안

원칙: 재부팅 없는 것 → 재부팅 1회로 끝나는 낮은 위험 → 커널 패치가 필요한 것. 매 항목마다 측정·롤백 경로·커밋을 따로 둔다.

| 순서 | 항목 | 재부팅 | 기대 효과 | 위험 |
| --- | --- | --- | --- | --- |
| 1 | **시간 동기화(NTP)** 설치 | 없음 | 시계 정확도 | 매우 낮음 |
| 2 | **스피커 PCM 정책**: 11/15 스피커 고장 원인을 다시 보고, 소리가 날 때만 열리고 쉴 때 닫히는 방식으로 | 없음 | 깨어 있을 때 −0.58W, 절전 −0.2~0.3W | 중간 (스피커 고장 재발 여부 관찰 필요) |
| 3 | **Wi-Fi 절전** 측정 도구(`iw`) 설치 후 측정, 효과 있으면 적용 | 없음 | 미정 | 낮음 |
| 4 | **Waydroid**: 물리 키보드 알림, 시작 시 검은 보정 창 숨기기 | 없음 | 사용감 | 낮음 |
| 5 | **카메라 표시등** 연결 (DT 한 줄) | 1회 | 개인정보 보호 | 낮음 |
| 6 | **a400000 부팅 실패**: 모듈 로드 순서 또는 지연 초기화 시간 조정, 여러 번 부팅으로 확인 | 여러 번 | USB-A·Surface Connect 데이터 안정 | 낮음~중간 |
| 7 | **절전 깨어남 수정**: USB SuperSpeed PHY 깨우기 처리(상위 패치 2개 중 하나씩) → 그다음 `sync_state` 정식 적용 → 긴 절전 측정 | 여러 번 | 절전 0.5~0.9W → 목표 약 0.27W | 높음 (멈춤 위험, 덮개 연 상태로 1회씩) |
| 8 | **동영상 하드웨어 디코더**(iris) 활성화 | 1~2회 | 영상 재생 시 최대 수 W 절감 | 중간 |
| 9 | **외부 모니터 연결 지연** 원인 분석과 수정 | 상황에 따라 | 사용감 | 미정 |

보류: Windows Hello IR 카메라, TPM, 조도 센서(지원 없음), Surface Connect 독·이어폰 단자(기기 없음).
