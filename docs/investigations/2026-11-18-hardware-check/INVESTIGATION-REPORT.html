목표

  1. 모든 하드웨어 부품 정상 사용
  2. 깨어 있을 때 배터리 소모 최적화 (지금 약 4.2~4.4W, 밝기 39%, 120Hz)
  3. 절전 중 배터리 소모 최적화 (지금 0.52~0.89W, 목표 약 0.27W)

지켜야 할 조건: 120Hz와 원래 CPU 거버너·범위 유지, 재부팅은 매번 승인, 한 번에 한 가지만 바꾸고 전후를 측정.

절전에서 바로 깨어나는 원인sync_state=timeout이면 SoC 전체 절전(CXSD)에 들어가지만, 아무것도 꽂지 않은 USB-C 두 포트의 SuperSpeed PHY 깨우기 인터럽트(PDC 17, 47)가 계속 켜져 2초 만에 깨어남
a400000 (USB-A·Surface Connect 데이터)리눅스 시작 전 단계가 12~18초 길어진 부팅에서, 지연 초기화 시간 초과와 USB 모듈 로드가 겹쳐 실패 (시험 부팅에서는 매번 실패)
동영상 재생하드웨어 디코더가 꺼져 있어 1080p 재생 시 +4.3W (4.4 → 8.9W)
GNOME 확장, Waydroid, ASPM대기 전력 영향 측정 오차 수준
카메라 표시등하드웨어 정상, 카메라와 연결 설정(DT) 없음
외부 모니터출력되지만 연결까지 2~39초, 원인 미분석

Windows Hello IR 카메라리눅스 지원 없음 (별도 과제)

수정 순서 제안

원칙: 재부팅 없는 것 → 재부팅 1회로 끝나는 낮은 위험 → 커널 패치가 필요한 것. 매 항목마다 측정·롤백 경로·커밋을 따로 둔다.
