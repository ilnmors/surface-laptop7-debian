그래픽 깨짐 복구

누락된 Microsoft GPU zap shader를 initramfs에 포함한 뒤 재부팅했고 사용자가 그래픽 정상 복귀를 확인했습니다. 현재 Secure Boot enabled이며 GMU 펌웨어 로드가 확인됐고 이전 zap shader 누락·GPU 초기화 실패·GMU OOB timeout은 이번 부팅 로그에 없습니다.

검증·다음 단계

카카오톡 로그인 자동 시작을 다시 활성화했습니다. 복구 중 껐던 Night Light·Blur My Shell은 현재 상태를 유지했습니다. 알림 필터의 실제 수신 표시 검증은 별도입니다.

절차와 기록 ↗
BOOT현재 부팅 확인

Secure Boot

재부팅 후 Secure Boot enabled·integrity lockdown 유지. 새 USB·SoundWire 모듈의 실제 srcversion이 설치한 교체본과 일치합니다.

검증·다음 단계

새 부팅 이미지에도 로고·폰트·GPU 펌웨어를 넣고 서명 검증했습니다. 모듈 로드 성공과 장치의 절전·오디오 안정성은 별도로 확인해야 합니다.

절차와 기록 ↗
POWERWi-Fi 서명 패치 설치 · 재부팅 대기

deep 절전과 복귀

이번 부팅에서 deep 약 65분 뒤 복귀 성공 1회·실패 0회입니다. Wi-Fi regulatory 대기·PCIe L2 timeout이 남았고, 복귀 종료부터 Wi-Fi 인증 시작까지 약 11.4초였습니다.

검증·다음 단계

상류 ath12k regulatory completion 수정을 빌드·설치했고, 기존 wifi7 모듈과 서명 강제 ARM64 시험에서 함께 로드됐습니다. 실제 절전 지연 개선은 재부팅 뒤 비교해야 합니다. 장치별 power trace는 부팅 자동 시작으로 추가했습니다.

절차와 기록 ↗
INPUT재부팅 후 사용자 개선 확인

터치패드 가장자리

정확한 045E:0C77 가상 터치패드의 geometric edge palm 제외를 끄는 수정이 적용됐고, 재부팅 후 사용자가 훨씬 좋아졌다고 확인했습니다.

검증·다음 단계

기존 IPTSD 보정과 타이핑 억제·다른 장치 설정은 유지됩니다. 모든 점프나 모든 접촉 문제가 사라졌다는 뜻은 아닙니다.

절차와 기록 ↗
BATTERY실측 기록 분석

절전·평균 배터리 소비

최근 절전 5.30시간: 73%→67%, 약 3.05Wh 사용. 평균 0.58W / 1.13%p/h. 깨어 있는 표본 2.67시간 평균 7.64W; 배터리 건강도 97.0%.

검증·다음 단계

현재 평균으로 단순 환산하면 완충 6.6시간. Windows 실측 비교 자료는 없습니다. MS Modern Standby 권장 5%/16h보다 소비율이 약 3.6배 높지만, Windows의 실제 이 기기 측정값은 아닙니다. 공식 웹 13h/영상 20h와 현재 혼합 작업은 직접 비교할 수 없습니다. 이 수치는 이번 Wi-Fi 절전·새 모듈·백그라운드 앱 설정 전의 기준값이며, 새 개선량은 아직 측정하지 않았습니다.

절차와 기록 ↗
AUDIO사용자 정상 청취 · 버스 오류 추적

간헐적 스피커 무음

사용자는 스피커가 정상인 것 같다고 확인했습니다. 기본 스피커 출력도 존재합니다. 다만 deep 복귀 뒤 12:11:26에 wsa884x Parity error 1회가 기록됐습니다.

검증·다음 단계

현재 정상 출력 설정은 유지합니다. 재발 시각과 버스 오류를 대조하며, 완전 해결로 판정하지 않습니다.

절차와 기록 ↗
INPUT미해결

터치스크린

Romulus13 I2C 0x34가 HID probe에 응답하지 않습니다. DT overlay만 켜졌다고 터치가 작동하는 것은 아닙니다.

검증·다음 단계

공개된 같은 Romulus13의 GPIO31 리셋까지 시험했지만 ENXIO가 유지됐습니다. 영구 DTB에 추가하지 않았습니다. 현재 장치의 정확한 reset·전원·펌웨어 증거가 더 필요합니다.

절차와 기록 ↗
HARDWARE일부 미해결

CPU·카메라

CPU9 PSCI -22는 미해결입니다. 카메라의 표준 최소 VBLANK 시험은 18.8→37.4fps로 증가했습니다. Romulus13에만 더 짧은 기본 프레임 간격을 쓰는 서명 모듈을 설치했고 재부팅 대기입니다.

검증·다음 단계

카메라 최대 노출이 짧아져 저조도 밝기·노이즈·깜빡임 확인이 필요합니다. 이전 gain helper는 재적용하지 않았습니다. CPU 코어 주소의 펌웨어 근거는 아직 없고 Secure Boot가 /dev/mem 접근을 차단하므로 추측 주소를 영구 적용하지 않았습니다.

절차와 기록 ↗
WIRELESS부팅 복구 · Wi-Fi PS 시험

Wi-Fi·Bluetooth

Bluetooth가 자동 복구돼 powered on입니다. Wi-Fi station 절전을 켠 뒤 공유기 응답 5/5 성공, 평균 약 5ms, 관찰 중 ath12k 오류는 없었습니다.

검증·다음 단계

Wi-Fi 절전은 NetworkManager에 저장했습니다. 실제 배터리 절감량과 반복 절전 후 재연결은 추가 측정이 필요합니다.

절차와 기록 ↗
DESKTOP분리 저장 완료

Fluent·GNOME·터미널

Fluent, User Themes, Blur My Shell, Vitals, Caffeine, AppIndicator, 터미널 색상, IBus, Plymouth를 desktop에 분리했습니다.

검증·다음 단계

Fluent Light는 유지하며 Android도 화이트 라이트 모드로 변경했습니다. 물리 키보드 사용 시 Android·GNOME 화면 키보드는 표시하지 않도록 설정했습니다.

절차와 기록 ↗
ANDROID로그인 자동 실행·백그라운드 통합

Waydroid·KakaoTalk

카카오톡 개별 창을 GNOME 로그인 8초 뒤 자동 실행합니다. 앱 로그인 데이터는 보존하며, 사용자가 창을 닫아도 수신하도록 Android 자동 컨테이너 절전 해제·카카오 idle 예외·알림 권한을 적용했습니다.

검증·다음 단계

실제 다음 로그인과 수신 알림은 추가 확인이 필요합니다. 호스트 절전은 유지합니다. 현재 PSS 약 1.26GiB는 고정값이 아니며, 다른 앱도 켜면 메모리가 추가됩니다. 카카오 외 앱은 설치하지 않았습니다. Android 가상키보드는 물리 키보드 연결 시 숨김, 시스템은 라이트 모드입니다. 잘못 물려받은 설정 앱 아이콘도 실제 노란 TALK 아이콘으로 수정했습니다.

절차와 기록 ↗
PROGRAMS게임 작업 보류

Steam·RimWorld

Steam SDK 경로 수정 뒤 SteamAPI 로드는 성공했습니다. FEX 환경에 Noto CJK 폰트를 추가했습니다.

검증·다음 단계

사용자 요청으로 게임 클릭·한글 표시 확인은 보류했습니다. Steam 전체 런타임과 게임 데이터는 이 bundle에 포함되지 않습니다.

절차와 기록 ↗
RESTORE모듈화 · 오프라인 검증

Surface 설치 재현 범위

상위 진입점이 kernel → drivers → patches → desktop → programs를 호출합니다. 각 단계에 SH/Python 진입점과 범위별 payload가 있습니다. 로고·폰트·GPU 펌웨어 hook, Wi-Fi PS 및 카카오 로그인·키보드·라이트 모드 설정도 각 설치 단계에 반영했습니다.

검증·다음 단계

새 설치를 실제 포맷해 검증한 것은 아닙니다. 미해결 하드웨어, 수동 MOK·재부팅·로그인, base Debian dependency와 Steam runtime 준비가 남습니다. Console 계정/서버 서비스는 repository 범위입니다.

절차와 기록 ↗
CONSOLE저장소 역할 분리

console.yaml · console.md

Caddy·code-server·확장 설정은 repository에 있습니다. Kopia의 workspace 백업 정책·공통 시간표·Persistent timer는 repository에만 추가했고 현재 Surface에는 적용하지 않았습니다. code-server 기본 확장 4개는 이제 서비스 inventory 대신 packages role 내부에서 관리합니다.

검증·다음 단계

console playbook 전체는 현재 일부 적용된 서비스보다 범위가 넓고 SSH CA 변경 등도 포함됩니다. Surface 하드웨어/테마/Android를 대신 설치하지 않습니다.

절차와 기록 ↗
MIGRATION도구·모의 검증 완료

Nextcloud DAV → OxiCloud

repository/tools에 dav-migrate.py.tmp와 README.md.tmp를 만들었습니다. Nextcloud read-only 백업, hash 검증, OxiCloud dry-run과 명시적 restore를 제공합니다.

검증·다음 단계

실제 서버 backup/restore는 실행하지 않았습니다. UUID rediscovery, 중단 후 재개, 원격 수정 보호와 손상 거부 등을 mock test로 확인했습니다. ACL·공유·외부 첨부파일은 별도입니다.

절차와 기록 ↗
MOBILE설치 보류

Samsung 연동

GSConnect/KDE Connect 계열로 알림·파일·클립보드 공유를 구성할 수 있습니다. 삼성 전용 Windows Phone Link/자동 핫스팟과 동일한 기능 범위는 아닙니다.

검증·다음 단계

사용자 요청에 따라 설치하지 않았습니다. 자동 핫스팟·잠금화면 동작은 휴대폰 버전과 앱 권한별 검증이 필요합니다.

절차와 기록 ↗
MAINTENANCE검증 완료

APT·Ansible 임시 경로

apt-get check와 upgrade 모의 실행 통과. 일반 apt update/upgrade는 유지하며 전역 업데이트 차단은 하지 않았습니다. Ansible의 비어 있는 root 소유 $XDG_RUNTIME_DIR 디렉토리는 삭제했습니다.

검증·다음 단계

local_tmp를 ~/.ansible/tmp로 바꿔 XDG 변수가 없어도 안전하게 사용자 홈으로 풀리도록 검증했습니다. 향후 새 Debian libinput은 가장자리 패치를 덮을 수 있어 새 보안 버전에 재반영해야 합니다.

절차와 기록 ↗
BOOT ART새 이미지 서명 · 다음 부팅 확인

로고·업데이트 글자

Debian13 버전 이미지 대신 간결한 Debian 워드마크로 교체했습니다. distro hook이 다시 덮지 않도록 보완하고 정적·대체 폰트를 포함했습니다. 실제 업데이트는 OpenEXR 보안 패키지 1개로 정상 완료됐습니다.

검증·다음 단계

패키지 로그는 영어 안내문이었고 기존 초기 이미지에는 지정된 Cantarell이 빠져 있었습니다. 폰트·로고 byte 확인과 호스트 문자의 누락 glyph 0개는 검증됐으나 다음 물리 화면 확인이 남았습니다.

절차와 기록 ↗
POWER드라이버 절전 확인 · CPU 유지

120Hz 유지와 전력 최적화

120Hz는 유지합니다. NVMe APST(100ms→PS4), SSD·Wi-Fi ASPM L1/L1.1/L1.2, USB root hub runtime suspend가 이미 활성화됐습니다. Wi-Fi station PS도 유지됩니다.

검증·다음 단계

4코어 부하 시험에서는 약 3GHz 제한 시 전력 21%·처리량 11% 감소가 관찰됐지만 일상 사용시간 예측은 아닙니다. 요청대로 ondemand·최대 3.4176GHz를 복원하고 영구 CPU 제한은 설치하지 않았습니다.

절차와 기록 ↗
PROGRAMS빈 동반 알림 확인 · 필터 적용

카카오톡 알림 본문

실제 수신 로그에서 quiet_new_message는 제목·본문이 비어 있고 new_message_v4는 내용이 정상 전달됐습니다. 카카오톡의 완전히 빈 동반 알림만 GNOME에 보내지 않도록 수정하고 세션을 재시작했습니다.

검증·다음 단계

가드 회귀 시험은 통과했습니다. 수정 후 실제 알림이 내용 있는 것 하나만 표시되는지 사용자 확인을 기다립니다. 대화 원문·로그 덤프는 저장하지 않았습니다.

절차와 기록 ↗
CONSOLE공식 ARM64 PET 복구

code-server Python 도구

Open VSX universal 확장에 없던 PET를 동일 버전 Microsoft 공식 linux-arm64 VSIX에서 복구했습니다. 실행·실제 Python 발견·중복 설치 방지 확인을 통과했습니다.

검증·다음 단계

현재 편집기 창은 Reload Window가 필요할 수 있습니다. 역할과 서비스 시작 시 복구도 반영했으며 새 교정 커밋 없이 원래 저장소 커밋에 합쳤습니다.

절차와 기록 ↗
DAV도구 검증 · 서버 접근 차단

Nextcloud 백업 → OxiCloud

백업/복원 진입점 분리와 브라우저 로그인 모의 시험은 통과했습니다. 실제 내보내기는 HTTPS 시간 초과로 중단됐고 최종 manifest가 없어 복원에 사용할 수 없습니다. 허용된 infra 읽기 전용 SSH도 연결 시간 초과입니다.

검증·다음 단계

서버 접근이 복구되면 새 디렉토리로 다시 내보내야 합니다. 임시 로그인 앱 암호 폐기는 확인되지 않았으므로 계정 보안에서 폐기 확인이 필요합니다. 실제 OxiCloud 반영은 하지 않았습니다.

절차와 기록 ↗
KEYBOARD요구 확인 · 영구 토글 차단 미지원

Fn 고정 모드

사용자는 미디어 기능 기본, Fn을 누른 동안에만 F1~F12, 짧은 Fn 입력으로 잠금 전환 금지·표시등 고정을 요청했습니다. 일반 Fn 토글 동작은 사용자 시험으로 확인됐습니다.

검증·다음 단계

실제 HID에서 잠금 표시가 읽기 전용 입력으로 노출되며 KEY_FN·Fn 설정 sysfs·표시등 출력 제어가 확인되지 않았습니다. 허위 고정이나 다른 기능을 깨는 키 매핑은 적용하지 않았습니다. 요청한 영구 모드는 미해결입니다.
