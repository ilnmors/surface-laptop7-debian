사용자는 미디어 기능 기본, Fn을 누른 동안에만 F1~F12, 짧은 Fn 입력으로 잠금 전환 금지·표시등 고정을 요청했습니다. 일반 Fn 토글 동작은 사용자 시험으로 확인됐습니다.

검증·다음 단계

실제 HID에서 잠금 표시가 읽기 전용 입력으로 노출되며 KEY_FN·Fn 설정 sysfs·표시등 출력 제어가 확인되지 않았습니다. 허위 고정이나 다른 기능을 깨는 키 매핑은 적용하지 않았습니다. 요청한 영구 모드는 미해결입니다.

설치와 기록

python3 setup.py --plan으로 실행 범위를 확인하고 bash setup.sh로 전체 설치합니다. python3 setup.py --component desktop처럼 선택할 수도 있습니다. 각 디렉토리의 setup.sh와 setup.py는 같은 구현을 사용합니다.

Console의 Caddy·Kopia·code-server·계정은 별도 repository에서 관리합니다. 최초 MOK 등록, 펌웨어 설정, 재부팅과 로그인은 수동입니다. 미해결 하드웨어 동작과 Steam 전체 런타임·개인 데이터 복원까지 자동화됐다는 뜻은 아닙니다.
